# Guia Salário-Maternidade

Landing page focada em VSL, com interface acolhedora e responsiva.

## VSL
O layout espera o arquivo de vídeo em:

`/vsl.mp4`

A VSL enviada tem aproximadamente 84 segundos. O arquivo precisa ser publicado junto do projeto para que o player funcione no site.

## Interface
- Headline com destaque para a possibilidade de benefício acima de R$ 6.000
- VSL em primeiro plano
- CTA após o vídeo
- Cards informativos
- FAQ
- Aviso de que o valor não é garantido
- Design mobile-first e acolhedor
